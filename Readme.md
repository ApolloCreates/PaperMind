# ResearchAI

An AI-powered multi-agent research assistant built with FastAPI, Next.js, LangGraph, PostgreSQL, Redis, Qdrant, and MinIO.

## Features

- Multi-Agent Research Pipeline
- Research Gap Detection
- AI Paper Generation
- Paper Review
- Citation Analysis
- Built-in Rich Text Editor
- Semantic Search
- Knowledge Base
- RAG Pipeline

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Zustand
- TanStack Query

### Backend

- FastAPI
- SQLAlchemy
- PostgreSQL
- Redis
- Qdrant
- MinIO

### AI

- LangGraph
- LiteLLM
- OpenAI
- Anthropic
- Gemini
